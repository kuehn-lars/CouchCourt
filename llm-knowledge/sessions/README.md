# Session logs

Dated logs, one per Claude Code session: `YYYY-MM-DD-<slug>.md`.

**Gitignored on purpose.** These are local scratch. They are not committed, not
reviewed, and nobody will read them in six months.

Their job is to be an *inbox*. At the end of a session, everything here that
will still be true in a month gets promoted into `decisions/`, `platform/`,
`reference/` or `experiments/` and linked from `index.md`. The promoted note is
the deliverable; this log is the raw material.

A log that never gets promoted out of was a session that learned nothing
durable, which is a perfectly normal outcome — just do not mistake the log for
the knowledge.

See `../README.md` for what belongs in the vault at all.
